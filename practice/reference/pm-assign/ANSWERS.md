# pm-assign 답안지 (에이전트에게 보여 주지 말 것)

과제 폴더만 다른 곳에 복사해서 연습한다. 이 파일은 "담당자 DM"과 "사용자" 역할을 할 때 쓰는 대본이다.

## 담당자(조장)만 아는 것 — 에이전트가 물어야 얻을 수 있다

| 주제 | 답 |
|---|---|
| priority의 의미 | 1이 가장 긴급. 전부 못 하면 가중치 합이 최대가 되게 한다. 가중치는 1 → 5, 2 → 2, 3 → 1 |
| latest의 의미 | 그 시각까지 **끝나야** 한다 |
| bay 열 | 베이가 다르면 이동과 방진복 교체에 15분이 걸린다. 같은 베이는 0분 |
| 중복 행(J15) | 같은 작업을 두 번 입력한 것. 한 번만 처리 |
| duration "90분"(J12) | 90으로 읽으면 된다 |
| skill 대소문자(J06 etch) | 구분하지 않는다 |
| LITHO 담당자 없음(J07) | 야간에는 배정 불가. 사유를 적어 보고하면 주간조가 처리 |
| J09 시간대(03:00~01:00) | 입력 실수. 배정하지 말고 사유를 적어 보고 |
| 작업 분할 | 불가. 한 작업은 한 명이 끊김 없이 |
| 날짜 | 22:00~23:59는 11일, 00:00~06:00은 12일 |

## 사용자(PM)의 결정

- 결과 형태: `out/assignments.csv`(`job_id,eng_id,start,end`, 시각은 `YYYY-MM-DD HH:MM`)와 `out/unassigned.csv`(`job_id,reason`). 여기에 엔지니어별 시간표 HTML 한 장(네트워크 없이 열림).
- 알고리즘: 권장안이 "단순한 기준선 먼저, 그 위에 개선"이면 수락. 처음부터 정수계획만 하겠다거나 기준선 없이 복잡한 방법을 권하면 기준선부터 하라고 고친다.
- 실행: `python plan.py data out` 형태.

## 구현 도중 던질 변경 (연습 6)

"조장 DM: E2가 00:00~01:00에 안전 교육이라 그 시간에는 작업을 못 합니다. 반영해 주세요."

## 채점

`python evaluate.py <과제 폴더>` (변경 반영 후에는 `--e2-block`). 위반 0건이어야 하고, 점수는 배정된 작업의 가중치 합이다.
