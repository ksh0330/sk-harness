# 야간 PM 작업 배정 (합성 연습 과제)

## 배경

식각·증착 라인의 설비기술팀은 매일 야간 근무에 예방 정비(PM) 작업을 엔지니어에게 배정한다. 지금은 조장이 엑셀에서 손으로 배정하는데, 긴급한 PM이 밀리거나 한 사람에게 일이 몰리는 일이 반복된다. 오늘 밤 배정을 자동으로 만들어 달라.

근무는 2026년 11월 11일 22:00에 시작해 12일 06:00에 끝난다.

## 제공 자료

- `data/pm_jobs.csv`: 오늘 밤 PM 작업 목록 (`job_id`, `eqp_id`, `bay`, `skill`, `duration_min`, `earliest`, `latest`, `priority`)
- `data/engineers.csv`: 야간 근무 엔지니어 (`eng_id`, `name`, `skills`, `shift_start`, `shift_end`)
- 담당자: 설비기술팀 조장. 플랫폼 DM으로 질문할 수 있다.

## 요구사항

1. 각 작업을 자격(skill)이 있는 엔지니어 한 명에게 배정하고 시작·종료 시각을 정한다.
2. 한 엔지니어가 동시에 두 작업을 하지 않는다.
3. 작업은 엔지니어의 근무 시간 안에서, 작업의 가능 시간대(`earliest`~`latest`) 안에 수행한다.
4. 배정할 수 없는 작업은 사유와 함께 따로 보고한다.
5. 긴급한 작업이 우선 처리되어야 한다.
6. 결과를 조장이 바로 쓸 수 있는 형태로 제공한다.

## 제출

- 명령 한 줄로 결과가 다시 만들어져야 한다.
- 실행 방법, 접근 방식과 그렇게 고른 이유, 검증 결과를 문서로 남긴다.

## 평가

규칙 위반이 없는지, 긴급 작업이 얼마나 처리됐는지, 결과물이 실제로 실행되는지, 왜 그렇게 풀었는지를 본다.
